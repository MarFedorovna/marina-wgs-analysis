# Расширенный анализ: частотные пороги, критерии ACMG/AMP, CNV, родство и происхождение

Скрипты лежат в `scripts/extended/`. Они работают с готовыми результатами пайплайна: совместным VCF с аннотацией VEP, итоговой книгой Excel и BAM. Пациентские данные и результаты в репозиторий не входят. Имена образцов в коде не записаны: они читаются из заголовка VCF и в выводе заменяются на A, B, C, D в порядке столбцов.

## Проверка типа данных

Перед запуском стоит сравнить глубину по кодирующим экзонам и по межгенным участкам. Если покрытие сосредоточено на экзонах (десятки × против долей ×), данные экзомные. Тогда глубокие интронные варианты не оцениваются, а CNV возможно искать только по глубине экзонов.

## Порядок запуска

Зависимости: `pysam`, `pandas`, `numpy`, `scipy`, `openpyxl`.

```bash
cd scripts/extended

# 1. Таблица аллелей из VCF с аннотацией VEP (можно по группам хромосом, затем склеить)
python extract_vcf_table.py --vcf cohort.vep.vcf.gz --contigs chr1,chr2,...,chr22 \
    --out-table var.tsv --out-genes genes.jsonl --header

# 2. Чувствительность отбора к порогу максимальной AF
python af_threshold_sensitivity.py --workbook итоговая_книга.xlsx --out af_thresholds.json

# 3. Частотные и вычислительные критерии ACMG/AMP для кандидатов по генам ГКМП
python acmg_frequency_criteria.py --workbook итоговая_книга.xlsx --table var.tsv --out acmg.json

# 4. Все аллели в генах ГКМП по положению относительно экзонов
python hcm_gene_variants.py --table var.tsv --genes genes.jsonl --out-prefix hcm_genes

# 5. Родство, контаминация, участки гомозиготности
python relatedness_checks.py --table var.tsv --out relatedness.json

# 6. Происхождение по частотам групп gnomAD
python ancestry_gnomad.py --table var.tsv --out ancestry.json

# 7. Скрининг CNV по глубине экзонов
python exon_depth_cnv.py --bam A=a.bam --bam B=b.bam --bam C=c.bam --bam D=d.bam \
    --x-copies 1,1,2,2 --cdot cdot.ensembl.GRCh38.json.gz --genes genes.txt --out-prefix cnv
```

## Методы и пороги

### Порог популяционной частоты

Используется поле «gnomAD AF max» итоговой книги. Пороги: 1%, 0,1%, 0,01% и 0,004%. Последний соответствует максимально допустимой популяционной частоте для ГКМП (Whiffin et al., 2017, doi:10.1038/gim.2017.26). Варианты без данных о частоте сохраняются при любом пороге и считаются отдельно.

### Критерии ACMG/AMP

Оцениваются только критерии, для которых не нужны данные о семье и функциональные тесты.

| Критерий | Условие | Источник |
|---|---|---|
| BA1 | FAF ≥ 0,1% | спецификация ClinGen для MYH7 (Kelly et al., 2018, doi:10.1038/gim.2017.218) |
| BS1 | FAF ≥ 0,02% | там же |
| PM2_Supporting | FAF < 0,004% | там же |
| BP4_Supporting / BP4_Moderate | REVEL ≤ 0,290 / ≤ 0,183 | Pejaver et al., 2022, doi:10.1016/j.ajhg.2022.10.013 |
| PP3_Supporting | REVEL ≥ 0,644 | там же |

Ограничения. Пороги частоты утверждены для MYH7 и к другим доминантным генам применены по аналогии; к генам с рецессивной связью они не применяются. FAF95 рассчитана приближённо: число аллелей восстановлено из AF экзомов gnomAD v4.1 и примерного числа аллелей в группе (AFR, AMR, EAS, NFE, SAS). Перед публикацией значения нужно сверить на сайте gnomAD. Для синонимических вариантов при максимальной delta-оценке SpliceAI ≤ 0,1 применяются BP4 и BP7 (Walker et al., 2023, doi:10.1016/j.ajhg.2023.06.002). В выполненном анализе итоговые значения FAF взяты с gnomAD v4.1 по объединённым экзомам и геномам, а SpliceAI — из SpliceAI Lookup. Вероятно доброкачественным считается вариант с BS1 и хотя бы одним поддерживающим критерием доброкачественности.

### Аллели в генах ГКМП по положению

Носителем считается образец с альтернативным генотипом, FT = PASS, DP ≥ 10 и GQ ≥ 20 при FILTER = PASS для сайта. Положение определяется по транскрипту MANE Select: кодирующий с изменением белка, синонимический, канонический сайт сплайсинга, область сплайсинга, интрон на расстоянии до 50 п.н., 51–300 п.н. и более 300 п.н. от экзона, UTR, окрестность гена ±5 т.п.н. Редкими считаются аллели с максимальной AF ≤ 1% или без данных о частоте.

### Родство, контаминация, гомозиготность

- Сайты: аутосомные двуаллельные SNP с FILTER = PASS и AF в геномах gnomAD 5–95%.
- Контаминация: доля ALT-прочтений в гомозиготах по референсу, отдельно на сайтах, где другой образец гомозиготен по ALT.
- Родство: сайты, где у каждого образца глубина ≥ 25, GQ ≥ 30 и чистый баланс аллелей (гетерозиготы 0,35–0,65). Считаются доля сайтов с противоположными гомозиготами (IBS0), оценка KING-robust (Manichaikul et al., 2010, doi:10.1093/bioinformatics/btq559) и суммарная длина участков ≥ 5 Мб без IBS0. Последняя сравнивается с ожиданием при перестановке блоков по 20 маркеров внутри хромосомы.
- На экзомных данных оценка KING-robust завышается из-за артефактных гетерозигот, поэтому вывод о родстве делается по IBS0 и длинным участкам.
- Участки гомозиготности: ≥ 1,5 Мб, ≥ 50 маркеров, разрыв между маркерами < 1 Мб, не более одной гетерозиготы на 100 маркеров.

### Происхождение

Генотип моделируется как биномиальный с частотой аллеля, равной смеси частот групп gnomAD (по умолчанию NFE, EAS, SAS, AFR). Доли подбираются методом максимального правдоподобия. Для каждого образца берутся сайты, где аллель несёт хотя бы один из остальных образцов, один SNP на 100 т.п.н. Интервалы получены бутстрепом. Это приближение без референсной панели; в gnomAD нет центральноазиатской группы.

### CNV по глубине экзонов

Средняя глубина считается по кодирующей части экзонов транскриптов MANE Select (координаты из cdot, Ensembl GTF). Исключаются дубликаты, вторичные и дополнительные выравнивания, прочтения с флагом QC-fail и MAPQ < 20. Глубина делится на медиану образца по аутосомным экзонам и сравнивается с медианой остальных образцов; для chrX учитывается число копий X. Экзон оценивается при медианной глубине ≥ 15×.

При четырёх образцах шум на уровне одного экзона велик (робастное SD log2 около 0,18), поэтому интерпретируются только гомозиготные потери, сдвиг по гену в целом и серии из трёх и более соседних экзонов. Делеции одного-двух экзонов этим методом не исключаются.
