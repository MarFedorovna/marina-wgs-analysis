# Продолжение уже выделенного набора

`transfer/download_cohort_views_dataset_v2.py` — узкий resume-only wrapper над точной проверенной v1. Он не создаёт новый набор и не выделяет место под новые файлы. Все артефакты должны уже существовать как проверенный готовый файл/жёсткая ссылка либо собственный `.part` с точной картой блоков, идентичностью файла и источника.

До чтения конфигурации подключения проверяется весь закрытый набор. Windows `GetFileInformationByHandleEx(FileStandardInfo)` должен показать AllocationSize не меньше полного ожидаемого размера каждого файла; логического размера или GetCompressedFileSize недостаточно. Sparse/compressed файлы отвергаются. Нижний резерв 5 GiB разрешён только после этой проверки; новые preallocate запрещены отдельной защитой.

```powershell
& "$env:NATIVE_SFTP_PYTHON" transfer/download_cohort_views_dataset_v2.py --plan "$env:COHORT_DATASET_PLAN"
& "$env:NATIVE_SFTP_PYTHON" transfer/download_cohort_views_dataset_v2.py --plan "$env:COHORT_DATASET_PLAN" --auth-config "$env:NATIVE_SFTP_CONFIG" --execute
```

Первую команду можно выполнить без авторизации и сети. Вторая продолжает тот же проверенный план, файлы и карты; прежний владеющий загрузчик должен уже завершиться. Wrapper, исходный `download_cohort_views_dataset.py` с SHA d73774c1b20062858c0097d81aa6c6bf740d9a3ad7f8324eaa2aaccfe2a2731f и прежний `native_sftp_download.py` располагаются рядом. Подключение, 16 клиентов, блоки, контроль источника, SIZE ONLY и абсолютный срок 06:45 UTC сохраняются. Большие данные заново не хешируются.

Состояние содержит только безопасную причину из разрешённых текстовых констант проверенного кода. Неизвестная ошибка обозначается классом без произвольного сообщения, адреса, логина или ключа. При снижении свободного места ниже 5 GiB перенос останавливается и сохраняет собственные блоки. Физически выделенный полный размер `.part` по-прежнему не равен прогрессу.
