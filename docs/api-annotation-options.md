# API для больших справочных баз

Основная аннотация пациентского cohort VCF остаётся локальной и использует фиксированные версии ресурсов. Вопрос пользователя о доступности API не включает автоматическую отправку пациентских вариантов, генотипов, фенотипов или полного VCF внешним сервисам.

| Источник | Официальный API / документация | Назначение |
|---|---|---|
| gnomAD | https://github.com/broadinstitute/gnomad-browser/blob/main/graphql-api/README.md | Выборочные популяционные AF/AC/AN; схема и доступность конкретного релиза проверяются отдельно |
| MyVariant.info | https://docs.myvariant.info/en/latest/doc/data.html | Агрегированные аннотации, включая dbNSFP, ClinVar и CADD; состав, сборка, версии и условия каждого исходного набора проверяются отдельно |
| VarSome API | https://docs.varsome.com/en/varsome-api-environments | Агрегированные сведения; доступ и конкретный пакет API проверяются отдельно |
| ClinVar | https://www.ncbi.nlm.nih.gov/clinvar/docs/access/ | E-utilities: поиск, summaries и полные записи; источник/версия записи сохраняются |
| ClinGen | https://search.clinicalgenome.org/kb/downloads | Курируемые данные, Evidence Repository и Criteria Specification Registry |
| Ensembl REST | https://rest.ensembl.org/documentation/ | Гены, транскрипты и VEP; удалённый текущий сервис не считается эквивалентом нашего cache115 |
| Orphadata | https://api.orphadata.com/ | Общие связи заболеваний, генов и фенотипов |
| PubMed / NCBI | https://eutilities.github.io/site/ | Библиографический поиск и получение публикационных метаданных |

Для воспроизводимых дополнений сохраняются точный запрос, дата, версия набора/записи, исходный ответ, источник и статус выполнения. Ограничения частоты, повторы, локальный кэш ответов и отрицательные/отсутствующие результаты обрабатываются явно. `not_found`, ошибка сети или недоступный релиз не означают доброкачественность варианта или отсутствие заболевания.

API не отменяет условия использования данных, регистрацию и платный доступ. OMIM/VarSome и другие ограниченные источники не считаются подключёнными без соответствующего доступа. Справочные выгрузки общих данных по публичным генам/заболеваниям отделены от запросов, раскрывающих варианты конкретных образцов. Вариантные запросы остаются выключены до отдельного согласования состава данных и конкретных получателей.
