# Линии анализа

## Analysis 1 — legacy, замороженный архив

Исходная линия работы использовала восемь раздельных нормализованных VCF: SNP и INDEL для каждого из четырёх образцов. Последующие этапы включали VEP/ClinVar, кардиопанель, таблицы по пациентам, межпациентные совпадения, предикторы и рабочую рукопись.

Эта линия сохраняется для аудита ранее полученных выводов. Она не является входом нового calling и не определяет новый список кандидатов.

Статус: `frozen legacy archive`. Реальные файлы хранятся вне GitHub, с приватным SHA-256 manifest.

## Analysis 2 — независимый FASTQ-based joint analysis

Новая линия начинается с исходных парных FASTQ. План: единый GRCh38 bundle → новые BAM/QC → отдельные gVCF → GenomicsDBImport/GenotypeGVCFs → полный cohort VCF → нормализация → полный VCF с site/genotype flags → quality subset → offline annotation → приоритизация → ручной ACMG/AMP.

Основная область: chr1–22, диплоидные SNV/малые indel. X/Y, mtDNA, coverage, CNV/SV и repeat expansions являются отдельными ветками.

Статус по доказательствам, доступным в Git: код готов; четыре BAM заявлены в рабочей документации; полный комплект gVCF/cohort VCF и заявленные counts требуют внешних PASS receipts и самих выходов.

Analysis 2 не импортирует старые кандидаты или классификации. Сопоставление с Analysis 1 допускается только после замораживания независимого нового результата и оформляется как аудит воспроизводимости.

## Неподменяемые идентификаторы результата

Каждый результат связывается с:

- commit SHA кода;
- container digest;
- reference FASTA SHA-256;
- resource manifest и версиями баз;
- входным private manifest;
- конфигурацией run/calls/samples вне Git;
- workflow receipts;
- выходным SHA-256 manifest.

Без этой цепочки файл нельзя уверенно отнести к Analysis 1 или Analysis 2.
