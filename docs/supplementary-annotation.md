# Дополнительные X/Y: calling, аннотация и функциональные таблицы

Это отдельное дополнение к завершённому аутосомному анализу. QC, поиск вариантов,
аннотация и таблицы имеют собственные статусы и receipts. QC PASS сам по себе
не означает, что варианты найдены или аннотированы.

1. `scripts/run_xy_germline.py` выполняет HaplotypeCaller с явной плоидностью
   отдельно для X-nonPAR, X-PAR и Y-nonPAR, затем CombineGVCFs/GenotypeGVCFs,
   нормализацию и мягкую фильтрацию. Исходный многoаллельный joint VCF сохраняется;
   при разложении удалённый ALT становится missing, а не референсным генотипом.
   [Подготовка и запуск](xy-germline-executor-v1.md).
2. `scripts/annotate_supplementary_callsets.py` ждёт настоящий PASS calling,
   проверяет его профиль и происхождение файлов, запускает офлайн VEP/ClinVar,
   AlphaMissense и настроенные локальные адаптеры. Источники, версии, покрытие
   источников и отсутствующие оценки фиксируются явно. Наличие базы не означает
   наличие оценки для каждого варианта.
3. Все фактически полученные строки транскриптной аннотации записываются в
   `WGS_SUPPLEMENTARY_EVIDENCE` внутри дополнительного VCF. Схема находится в
   `WGS_SUPPLEMENTARY_SCHEMA`. После сохранения BGZF строки читаются обратно и
   проверяется точное восстановление исходных векторов. `master.from-vcf.tsv.gz`
   формируется из сохранённого VCF и используется для таблиц.
4. Экспорт выдаёт общий и индивидуальные top-20, матрицу точных аллелей,
   таблицы всех функциональных категорий для каждого образца, `shared_ge2` и
   `all4`. Это полные таблицы категорий, а не только варианты из top-20.
   В индивидуальных VCF пакет содержит строки только выбранного образца.
   Итоговые manifest/receipt пересчитываются после этого удаления чужих строк.

## Где запускать

Команды выполняются в Linux-терминале сервера из каталога кода. Профили,
конфигурации образцов, данные и ключи остаются вне Git. Используйте подготовленный
приватный профиль и его точный SHA256, а не пример или старую квитанцию:

```bash
python3 scripts/run_xy_germline.py \
  --profile /path/to/private/ROOT-reviewed-xy-profile.json \
  --profile-sha256 ACTUAL_PROFILE_SHA256 --execute

python3 scripts/annotate_supplementary_callsets.py run \
  --profile /path/to/private/ROOT-reviewed-annotation-profile.json \
  --reviewed-profile-sha256 ACTUAL_PROFILE_SHA256 --execute
```

Обработчик аннотации можно запустить, пока calling ещё идёт: он ждёт реальную
успешную квитанцию. Нужны проверенные версии Python/pysam, Docker, VEP, кэш,
референс, AlphaMissense и локальные ресурсы из профиля. `prepare --help` описывает
создание кандидата профиля; подготовка кандидата не запускает анализ.

Текущие исполнители ограничены отдельным абсолютным сроком этого серверного
запуска. Истёкший профиль не следует переиспользовать: новый запуск требует новой
проверки времени, ресурсов, входных файлов и профиля. Старый бюджет и готовые
аутосомные результаты не подменяются.

## Что означает результат

`PASS_XY_GERMLINE_CALLING` означает готовый дополнительный вызов вариантов.
`PASS_SUPPLEMENTARY_ANNOTATION` означает завершённую аннотацию и переносимый VCF.
`PASS_SUPPLEMENTARY_ANNOTATION_AND_ALL_FUNCTIONAL_VIEWS` означает также готовые
таблицы. Ранжирование исследовательское; клиническая ACMG-классификация не
назначается автоматически. Профиль плоидности из QC не подтверждает кариотип.

MT обрабатывается отдельно: его гетероплазмия, фильтры и частотные источники не
заменяются ядерными правилами GQ/плоидности. Этот X/Y-исполнитель MT не вызывает.
