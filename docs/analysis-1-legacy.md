# Паспорт Analysis 1

Статус: замороженный архив; не использовать как вход Analysis 2.

## Вход

- четыре образца;
- по одному SNP VCF и одному INDEL VCF на образец;
- всего восемь VCF.

## Сохранённые этапы

- нормализованные SNP/INDEL VCF;
- VEP/ClinVar-аннотация;
- функциональная и кардиопанельная фильтрация;
- итоговые таблицы кандидатов;
- таблицы consequence classes;
- межпациентные совпадения вариантов и повторяющиеся гены;
- предикторы, популяционные частоты и рабочая ACMG/VarSome-информация;
- рукопись и supplementary materials.

## Частный архив должен содержать

- восемь исходных для этой ветки VCF;
- все промежуточные таблицы, а не только 29 финальных вариантов;
- код и точные команды преобразований;
- private SHA-256 manifest;
- ссылки на Word/Excel/Google Drive snapshots;
- журнал известных ограничений и незавершённых экспертных интерпретаций.

Реальные пути, sample IDs, variant coordinates и checksum manifest не публикуются в GitHub.
