# Перенос завершённой выдачи

`transfer/download_cohort_views_dataset.py` переносит только закрытый набор из проверенного приватного плана. [Команды PowerShell](QUICKSTART.md#сохранить-завершённый-набор-на-компьютер).

Параметры: обязательный `--plan`; `--auth-config` нужен только с `--execute`; необязательный `--small-only` выбирает файлы до 20 MiB. Без `--execute` выполняется локальная проверка метаданных и места без подключения и чтения ключа.

Manifest и workflow receipt должны подтверждать один завершённый набор с совпадающими путями, размерами и SHA. Разрешены только артефакты выдачи, сама квитанция и manifest. Произвольные пути, базы, BAM и gVCF отвергаются. Существующее подключение сохраняет проверку ключа сервера; секреты не копируются в план или журнал.

16 постоянных SFTP-клиентов записывают непересекающиеся блоки по 64 MiB в заранее выделенные файлы. Завершение блока записывается в долговечную карту только после полной записи, fsync и проверки неизменности удалённого файла. Данные читаются окнами до 8 MiB. При ошибке собственные `.part` и карты сохраняются; автоматического перезапуска нет. Для продолжения используется та же проверенная команда и план. Незавершённые блоки переписываются в пределах собственного временного файла, завершённые переиспользуются.

Размер `.part` показывает выделенное место, а не полученные данные. Статус `PREPARING` означает подготовку файлов; `DOWNLOADING_CLOSED_DATASET_CHUNKS_SIZE_ONLY` — перенос. Счётчики учитывают подтверждённые блоки и проверенные локальные псевдонимы. `SMALL_PHASE_COMPLETE_LARGE_FILES_PENDING` не означает завершение всего набора; полное завершение — `PASS_ALL_CLOSED_DATASET_FILES_SIZE_ONLY`.

Основной VCF и индекс можно переиспользовать только по проверенной квитанции предыдущей загрузки и точному совпадению идентичности источника. Создаётся жёсткая ссылка на том же томе, без второй копии. Переименование `.part` в готовый файл допускается лишь после всех блоков и проверки источника. Отличающийся готовый файл не заменяется. Редкий сбой между переименованием и записью квитанции требует проверки: загрузчик откажется автоматически принимать такой файл.

Перед выделением места проверяется весь выбранный остаток плюс 15 GiB резерва. Во время записи проверяются резерв, маркер паузы и абсолютный срок из приватного плана. Это отдельный срок переноса, не разрешение продлевать анализ или работу VM. Проверка локальных данных SIZE ONLY; ожидаемый серверный SHA сохраняется как происхождение, но новый SHA содержимого не вычисляется.

Откройте локальный `index.html` внутри зеркала набора. Ссылки сохраняют серверные относительные пути. Top-20 и небольшие отчёты передаются первыми, но полноту выдачи подтверждает только итоговый статус всех выбранных файлов.
