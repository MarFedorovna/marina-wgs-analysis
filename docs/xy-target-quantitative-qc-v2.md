# X/Y: проверка по публичным экзонным мишеням

`scripts/xy_target_quantitative_qc_v2.py` дополняет разреженную проверку v1. Мишени выбираются до чтения BAM из локального GENCODE49: экзоны protein_coding-генов, включая UTR, вне PAR. Общие интервалы объединяются, делятся на непересекающиеся окна ≤500 оснований; N/IUPAC исключаются. Аутосомные экзонные контроли сопоставлены по GC и длине. Реальный дизайн захвата неизвестен, поэтому эти контроли не считаются совпадающими с bait-панелью.

Независимая SNP-панель содержит распространённые двухаллельные SNP X вне PAR внутри публичных экзонов: AF 1000 Genomes phase3 0,1–0,9, расстояние ≥1 кб, максимум 20 тысяч сайтов. Генотипы и покрытие четырёх образцов не используются для выбора сайтов. Источники, реальные расстояния и число сайтов фиксирует публичный manifest. Более плотная панель имеет остаточное LD; интервал по числу сайтов не означает диагностическую уверенность.

Чтение через BAM-индекс и фильтры сохранены из [v1](xy-sparse-quantitative-qc.md): MQ≥30, BQ/BAQ≥20, исключение duplicate/QC-fail/secondary/supplementary, удаление перекрытия пар. Сохраняются глубина, REF/ALT/прочие основания, AB, причины исключения и доля гетерозигот среди классифицированных сайтов. F остаётся описательным прокси по внешней глобальной AF, требует ≥100 сайтов и ≥10 интервалов по 10 Мб. Пол, кариотип и плоидность не назначаются.

Для каждого экзонного окна выводятся средняя глубина и охват ≥1/5/10. Метрики относятся к выбранным публичным экзонам, а не ко всей Y. PAR, N и маппируемость — разные ограничения; MQ не доказывает уникальность картирования. Исходная v1-выдача сохраняется.

```bash
python3 scripts/xy_target_quantitative_qc_v2.py prepare \
  --config /PRIVATE/technical-xy-qc-config.json \
  --panel /PUBLIC_TARGETS/x_nonpar_common_snps.tsv \
  --panel-manifest /PUBLIC_TARGETS/validated-contract.json \
  --targets /PUBLIC_TARGETS/targets.tsv \
  --output /NEW_QC_V2_OUTPUT --profile /PRIVATE/candidate-v2.json \
  --deadline-utc EXACT_SEPARATE_QC_DEADLINE_UTC
```

```bash
python3 scripts/xy_target_quantitative_qc_v2.py run \
  --profile /PRIVATE/ROOT-reviewed-profile-v2.json \
  --reviewed-profile-sha256 EXACT_SHA256 --execute
```

Без `--execute` выполняется только просмотр плана. Новый каталог вывода и профиль обязательны. Пределы: 16 CPU, ≤24 ГиБ, 40 минут и отдельный абсолютный срок. Для жёсткого ограничения всего дерева процессов проверенный запуск оборачивается в `setsid timeout --signal=TERM --kill-after=10s` с оставшимся временем до срока; существующие процессы не включаются в эту группу. Полный BAM и исходный итоговый VCF не сканируются и не изменяются.
